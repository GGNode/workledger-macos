# 变更记录

## 0.1.0 公开发行修订

- 简报优先提取回复末尾的结果句，保留日期开头；缺少文件路径时使用已有描述，避免空白卡片。
- 已捕获的网页用户消息不会因 DOM 重绘再次上报；助手的流式回答仍可更新并保留原时间。
- 适配当前 ChatGPT search-unit 布局；兼容旧布局，避免重复消息。
- 排除 Codex 桌面自动附带上下文，解析异步回答信封；不由消息通道推断物理输入者。
- 发布脚本使用当前 gh 登录账号，移除部署者专属文档，使用通用文档和合成测试。
- CI 安装固定的 jsdom 开发依赖及可选 Zstandard 解码器，执行 Linux/macOS 六组测试；默认只读权限。

本地回归：80 项 Python、18 项 JavaScript 通过。在线 CI 的状态以对应提交的 Actions 结果为准。
