# 变更记录

## 0.2.0 · 证据驱动的每日工作分析

- 对已经合法但遗漏引用或归类的模型响应，最多追加两次仅包含遗漏记录的分析；结构错误可尝试两个较小分块。继续使用同一缓存和预算，所有追加引用与归属重新严格校验；超时、登录、服务策略或工具执行请求不会通过补分析绕过。

- 免费模型分析强化仅本次代理的结构与归属指令，并在证据之后重复简短输出契约；格式修复携带有长度上限的原无效响应用于纠错，明确不将其作为事实证据。原有账户、插件及默认模型保持正常使用。

- 每个分析分块保持单一原生任务，跨任务公平轮询并完整保留长记录；给模型明确的归属依据和成果资格提示，减少不同任务之间的引用和结果混淆。
- 删除没有任何引用的独立推测，同时保留覆盖缺口；虚构引用、错误的人类归属、未成功结算的工具成果及无引用的问题仍严格拒收。

- 强化日报分析代理的系统指令：日志中的路径、命令、开发契约和用户请求仅作为不可信历史证据，不能触发文件读取或任务执行。保持工具自动拒绝和失败检测，缺失内容明确待验证。

- 本机适配：升级优先沿用已有 WorkLedger 虚拟环境；修正 macOS 临时目录符号链接的测试比较；已有数据库的读取连接不再重复申请架构写锁，避免重解析期间面板和报告状态被阻塞。
- 控制面板启动采用轻量、需配对认证的健康检查，不再等待全量日志诊断；模型 HTTP 错误响应在分类后关闭。
- 大量历史重解析逐文件提交已完成的数据与签名，失败文件仍整体回滚；后台采集繁忙时，手动日报读取一致的已提交快照并醒目标明尚未刷新，避免无限等待采集锁。
- 修复 OpenCode 免费模型兼容性：`deny` 全部工具会触发服务端 `FreeTierError`；改用原生 `ask` 和显式非交互自动拒绝，保留工具定义但不批准执行。失败记录保存错误事件来源与 HTTP 状态，不留请求正文/认证头；不再将该错误解释为必须更换模型。旧失败缓存不会阻止修复后的调用；错误分类只看服务响应，日志中引用的旧错误不会污染本次判断。

- 模型遗漏部分记录的引用/归类时，保留通过校验的分析；遗漏记录和部分处理分块明确记入覆盖缺口，不计为已完成。无效引用、错误归属和非法结构仍拒收。
- 降级状态改为“分析未完成”，避免把输出结构或校验失败误读为模型连接不可用。
- macOS 退出进程组的清理权限错误不再覆盖原始解析错误；活跃子进程仍终止。问题对象提供明确字段结构，格式修复提示定位具体字段，避免把字符串问题说明当作已验证分析。
- 早期请求包补充同一原生任务当天较晚的交付说明及成功写入，并保留时间、归属与部分输入标记；避免仅因包内没有结果便误断言产物尚未完成。
- 分析部分完成时，未分析记录的通用观察摘要移入折叠依据区；HTML 与 Markdown 正文及主题导航只呈现已生成的语义分析，JSON 和原始证据完整保留。
- 大证据包超时后，已完成的分析可进入一次独立综合阶段，继续受原总调用数和时限约束；原始分析保留后续综合预算，避免预算耗尽后没有今日重点。登录/服务拒绝不会因阶段切换被重新开启。
- 模型证据包及前情显式传递工具结算成功状态与证据类型；格式修复重试说明具体校验约束，减少将待确认文档变化误当工具执行成功的重复无效响应。

- 新增用于日常报告生成的 OpenCode CLI 后端：显式 `--dir`，复用正常登录/配置/模型/插件，临时禁用分析代理工具与共享，不读取认证或创建独立 XDG。
- 以完整保留证据进行分块理解、语义主题归并、进展与错误恢复分析、全天综合；不再从前 60 条短卡片摘要。长记录和大规模任务有公平调度、覆盖与截断声明。
- 原生委派、fork、当天/历史、用户要求/成果、人类确认/Agent 自述/工具验证保持分开。断言引用真实证据并检查时间、角色和证据强度；不把引用检查宣称为语义自动证明。
- HTML、Markdown、JSON 共用分析结果。主视图改为今日重点与自然中文工作主题；常规已恢复错误、原始消息、工具结果、会话树和计数默认折叠。新增一致的状态、可点击证据及响应式页面。
- 子进程及 HTTP 调用具备超时、输出上限、错误分类、有限重试、缓存和失败冷却；恢复旧报告与版本指针发布；浏览报告不会触发推理。
- 登记并排除分析自身的 session、明确后代、私有产物和精确探测；正常 WorkLedger 开发不会因名字相同而排除。
- 补充工具结果正文、操作关联和来源截断标记；保留既有稳定 ID 和人工归属。浏览器选择器/配对协议不变。
- 控制面板新增后端、目录、路径、预算与缓存设置；异步报告状态查询，慢分析不暂停采集；新增 CLI 配置及强制重分析入口。
- 增加脱敏语义验收、真实子进程接口模拟、报告持久化和 UI 检验，详见 `ANALYSIS_TESTS.md`。真实 Mac / OpenCode / 私有日志语义验收仍由本机执行，不能以测试替身冒充通过。

## 0.1.0 公开发行修订

- 简报优先提取回复末尾的结果句，保留日期开头；缺少文件路径时使用已有描述，避免空白卡片。
- 已捕获的网页用户消息不会因 DOM 重绘再次上报；助手的流式回答仍可更新并保留原时间。
- 适配当前 ChatGPT search-unit 布局；兼容旧布局，避免重复消息。
- 排除 Codex 桌面自动附带上下文，解析异步回答信封；不由消息通道推断物理输入者。
- 发布脚本使用当前 gh 登录账号，移除部署者专属文档，使用通用文档和合成测试。
- CI 安装固定的 jsdom 开发依赖及可选 Zstandard 解码器，执行 Linux/macOS 六组测试；默认只读权限。

本地回归：80 项 Python、18 项 JavaScript 通过。在线 CI 的状态以对应提交的 Actions 结果为准。
